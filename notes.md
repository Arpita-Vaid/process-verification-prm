# Project Notes

My project is a Process Verification System for improving the reliability of mathematical reasoning from Large Language Models. The system will generate multiple solutions for the same problem and use a smaller Process Reward Model to check the reasoning steps in those solutions. It will then select the solution with the best reasoning score instead of simply trusting the first answer generated by the LLM. I will compare this approach with normal LLM generation and other simple selection methods to see whether it improves accuracy. I will also study how the number of generated solutions affects accuracy, time, and computational cost.
